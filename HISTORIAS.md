# Histórias de Usuário e Prioridades

**Prioridade das Tarefas:**
1. Sistema de Votação (Alta - Faz as pessoas interagirem rápido).
2. Categorias/Tags (Média - Ajuda a organizar o fórum).
3. Busca (Baixa - Depende de muito volume de conteúdo para ser útil).

## História 1: Sistema de Votação (Prioridade 1)
**Como** usuário do fórum,
**Eu quero** poder curtir ou descurtir uma pergunta,
**Para** mostrar quais perguntas são melhores para a comunidade.

**Critérios de Aceitação:**
- [ ] Tem que aparecer um botão de curtir na pergunta.
- [ ] O número de curtidas tem que atualizar na mesma hora.
- [ ] A pessoa não pode curtir a mesma pergunta duas vezes.

## História 2: Categorização (Prioridade 2)
**Como** usuário do fórum,
**Eu quero** colocar tags (ex: #tecnologia) nas perguntas,
**Para** organizar os assuntos.

**Critérios de Aceitação:**
- [ ] O formulário de pergunta deve ter um espaço para digitar a tag.
- [ ] A tag tem que aparecer junto da pergunta.

## História 3: Busca (Prioridade 3)
**Como** usuário,
**Eu quero** uma barra de pesquisa,
**Para** achar perguntas antigas facilmente.

**Critérios de Aceitação:**
- [ ] Ter uma caixa de texto no topo do site para pesquisar.
