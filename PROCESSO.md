# Processo Ágil Escolhido: Kanban

Para o desenvolvimento das novas funcionalidades do ESM Forum, optei por utilizar o modelo **Kanban**.

## Justificativa da Escolha
O Kanban é extremamente adequado para este cenário de manutenções e adições de features específicas porque:
1. **Foco no Fluxo Contínuo:** Como temos 5 tarefas independentes e bem definidas (votação, busca, tags, perfil e notificações), o Kanban permite puxar uma tarefa por vez, focando na entrega sem a necessidade de planejar Sprints fixas.
2. **Simplicidade:** Para um desenvolvedor (ou uma dupla), o overhead de cerimônias do Scrum seria desnecessário. 
3. **Priorização Clara:** A coluna "To Do" foi ordenada por prioridade (Perfil -> Tags -> Busca -> Votação -> Notificação), garantindo que a funcionalidade de maior valor seja desenvolvida primeiro.
